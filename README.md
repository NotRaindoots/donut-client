# Donut Client

A **vibecoded** client-side Fabric mod for **Minecraft 1.21.11**, with visual tools, movement modules, schematic building and streaming overlays.

Fork it, modify it, fix bugs, improve it, or use the code as a reference point for your own projects.

**Source and required assets only. No prebuilt JARs are included.** To build it yourself, use **JDK 21** and **Gradle 9.2.1**, then run `gradle build`. Requires Fabric Loader 0.18.4+ and Fabric API 0.141.4+1.21.11.
